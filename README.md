# timely.you — app downloads

Public releases for the **timely.you** time-tracking apps (Windows + Android today; iOS/macOS planned). The source lives in a private repository — this repo hosts the installers and the auto-update manifest.

## Install

- **Windows**: download `timely-you-<version>-windows-setup.exe` from the [latest release](https://github.com/youserpath/timely/releases/latest) and run it. The app auto-updates from then on (checks on launch and daily at 08:00).
- **Android**: download `timely-you-<version>-android.apk` and open it (allow installs from your browser when prompted).

`latest.json` is the machine-readable update manifest used by the desktop app — no need to touch it.
